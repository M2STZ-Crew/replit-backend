How to install

  1. Download the APK Tap "Download latest APK" and wait for the file to finish downloading.
  2. Open the downloaded file Open the APK from your download notification or your Downloads folder.
  3. Allow installation if prompted If Android asks, open the settings it shows and allow installing from the browser or file manager you used. It is usually called "Install unknown apps" or "Allow from this source". The names differ by phone and Android version.
  4. Complete installation Go back to the installer and follow Android's prompts. Open RepLiT once it finishes. Already have RepLiT? It updates in place, and you stay signed in.

If Play Protect asks to scan the app, let it. If it blocks the installation or flags the app as unsafe, stop and ask your organization's coordinator or the central hub (Barangay 76) before going on.

Need help installing RepLiT?

Ask your organization's coordinator, or the central hub (Barangay 76). Say which phone you have, its Android version, the RepLiT version above, and the message you saw.
